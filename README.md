## Overview

QoL Research adds an extended technology tree with practical upgrades: faster hand-crafting, larger inventory stacks, quicker character speed, and equipment grid bonuses unlockable through standard research.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Quality of Life Research** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Crafting Speed** | Tech levels that multiply hand-crafting speed up to 10x |
| **Stack Bonuses** | Research additional inventory stack size for common items |
| **Logistics Perks** | Unlock personal roboport range and bot speed improvements |
| **Lab Efficiency** | Research science-pack consumption reductions for all lab tiers |
